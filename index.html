Thermal Pad Analysis Tool (v4.0) 完整使用說明與工程規範

ME / Thermal Engineering 導熱墊公差堆疊、逆向最佳化與材料選型操作手冊

1 標準選型流程與 Main / Second Source 多組機構管理

  • 步驟 1（機構結構與公差模型）：選擇散熱片型態（平板 Flat、下凸 -A 縮減間隙、上凹 +A 增加間隙），並依專案規範切換 RSS（均方根統計公差） 或 Worst-Case（極值公差）。
  • 步驟 2（尺寸鏈與設計規格上下限）：輸入 A（HS 台階）、B（螺柱/Nut 高度）、C（晶片總高度）、E（額外間隙或 PCB 翹曲），以及該晶片的壓縮率上下限、最大承受壓力 (PSI) 與最差熱阻上限 (Rmax)。右上角可切換「±對稱同步」或「±獨立公差」。
  • 多組機構管理（Main / Second Source）：點擊「存為機構條件」可保存多組不同公差或上限的機構條件（點擊標籤上的鉛筆可重新命名；點擊標籤可回填至主畫面修改，再按「更新」覆寫）。
  • 步驟 3（選料與跨組智慧交集搜尋）：可直接下拉選擇料號，或點擊「自動搜尋通過 PAD」；當已儲存多組機構條件時，系統預設勾選「跨組交集」，自動篩選出所有機構組別皆通過的共用料號並依「綜合適配度評分 (1~99分)」排序推薦。

2 機構尺寸逆向最佳化引擎（v4.0 新功能）

當機構尚在設計階段、或既有 Gap 找不到合適 PAD 時，點擊步驟 2 下方的「機構尺寸最佳化（自動反推 Nut B / HS Step A）」可啟動逆向搜尋引擎：

模式 1：調整 Nut 高度 B

固定目前 HS 台階 A 與晶片 C，依指定 CNC 步進（0.01 / 0.05 / 0.10 mm）掃描最佳螺柱高度 B 與最適配 PAD 組合。

模式 2：調整 HS 台階 A

固定 Nut 高度 B，自動在 ±A 範圍內搜尋最佳下凸 (-A) 或上凹 (+A) 加工深度，找出最佳熱阻與應力平衡點。

模式 3：多 Chip 共用 B + 各自 A

針對已存的多顆晶片條件，自動尋找共用同一 Nut 高度 B 且各自搭配最佳 HS Step A 的方案；預設開啟「共用同一款 PAD 料號 (BOM 歸一化)」。

3 工程規格判定基準 (PASS / WARNING / FAIL)

  • FAIL不相容 / 超出規格：最小壓縮量 Min X ≤ 0（脫壓無接觸）、最大壓縮率超出規格書曲線最大測試點（達壓縮極限且曲線截斷），或任一指標超出使用者設定的設計上下限。
  • WARNING警告邊界：所有指標皆未超標，但已進入設計上限的 80% 警戒區，或最小壓縮率低於 下限 + 10%（如設定下限 10% 時，低於 20% 即警戒），或最小壓縮率低於規格書最小測試點（端點保守截取）。
  • PASS設計安全：壓縮量、壓縮率區間、最大反推應力與最差熱阻皆具備充足安全餘裕。

4 綜合適配度評分標準 (1～99 分制扣分模型)

在「自動搜尋通過 PAD」與「機構尺寸逆向最佳化」中，系統以滿分 100 分為基準，依下列 4 項工程指標進行連續扣分（最終分數限制於 1 ～ 99 分），分數越高代表散熱效能、結構安全與公差餘裕越均衡：

1. 熱阻裕度表現 (最高扣 38～45 分) 權重最高

依最差熱阻 Rmax 佔熱阻上限之比例連續扣分（若未設熱阻上限，則依同批候選料號之相對區間進行正規化評比），確保散熱效能優先。

2. 結構應力保護 (最高扣 28 分) >80% 上限才扣分

當 Max PSI 位於上限 80% 以內的安全區時完全不扣分（0 分）；超過上限 80% 進入警戒區後才依超標程度連續扣分（最高 28 分），避免無故懲罰安全區內的導熱墊。

3. 壓縮率區間平衡 (最高扣 22 分) 上限80% / 下限+10%

當 Max CR 超過上限 80%，或 Min CR 低於 下限 + 10% 警戒線時才依偏離程度連續扣分；位於安全區間內則完全不扣分。

4. 曲線低端外插懲罰 (扣 8～20 分) 保守防呆修正

若 Min CR 低於規格書最低測試點，系統除依斜率保守外推估算高熱阻外，另依偏離程度額外扣 8～20 分，避免誤選低壓接觸不良的過薄墊片。

※ 註：在「機構尺寸逆向最佳化」中，若不同加工深度的適配度分數相近，系統會自動加計 -|Step A| × 0.25 作為同分決勝權重，優先推薦 CNC 加工深度較淺（或平板 A=0） 的低成本結構方案。

5 核心工程公式與單位換算工具

  • 壓縮量 (X)：Nom Gap = B - C + E ± A（下凸取 -A、上凹取 +A、平板 A=0），標稱壓縮量 Nom X = D - Nom Gap。
  • 壓縮率 (CR) 分母模式：支援切換 D_actual（動態實際分母：Min CR = Min X / D_min、Max CR = Max X / D_max，最貼近真實公差極值）與 D_nom（標稱分母）。
  • 曲線內插與等效熱導率 (keff)：以 Max CR 查壓力曲線得 Max PSI；以 Min CR（最鬆狀態）查熱阻曲線得最差熱阻 Rmax；實際等效熱導率 k_eff = (BLT_mm × 10) / Rth_(cm²·K/W)，反映含接觸熱阻的真實傳熱表現。
  • 步驟 4（接觸面積與即時單位換算）：輸入晶片長寬 (L × W) 後，可即時雙向換算 PSI / kPa / kgf/cm²、由總鎖附力 (kgf / N / lbf) 反推壓力，以及 cm²·K/W / in²·°C/W / °C/W (總熱阻)，並自動同步至設計上限。

6 AI 匯入 PDF 建檔、材料庫與分組報告匯出

  • AI 匯入 PDF：上傳原廠 Datasheet 後勾選含有物性表與曲線圖的 1～2 頁，Gemini 視覺模型會自動拆解多厚度 SKU、進行像素級雙軸座標讀值，並將 kPa / MPa / in²·°C/W 統一換算為標準單位；核對右側雙軸曲線圖無誤後可一鍵安全合併寫入 Google Sheets 雲端材料庫。
  • 材料庫管理：支援依「品牌 + 系列」折疊檢視、手動新增/編輯料號，並可直接從 Excel 複製多列曲線數據貼上；上傳覆寫雲端前會自動執行差異比對確認。
  • 報告預覽與分組 CSV 匯出：將各組評估方案「加入報告」後，系統會自動依相同機構條件 (A/B/C/E 與規格上限) 歸類分組（可自訂組別名稱），匯出結構清晰、不重複冗餘的工程比較報表。
Tip: 點擊各指標卡片右上角的「公式」按鈕，可隨時展開即時帶入數值的詳細算式。
