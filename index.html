Thermal Pad Analysis Tool v3.2 使用說明與工程規範

1. 公差疊加與壓縮率計算

• 支援 RSS (Root Sum Square) 與 Worst-Case（極值疊加） 兩種公差模型，並可切換散熱片型態（平板 Flat / 下凸 -A / 上凹 +A）。

• 調整 D: Pad 原始厚度 時，±Tol 會自動連動為 ±10%，亦可手動微調或切換「非對稱公差」。

2. 工程規格判定基準（80% 警戒區）

• PASS：所有指標均在安全範圍內，且距離上下限保留超過 20% 餘裕。

• WARNING：壓縮率、壓力或熱阻已達設計上限的 80% 警戒區（或壓縮率低於下限 1.2 倍內、低於規格書最小測試點）。

• FAIL：最小壓縮量 Min X ≤ 0（脫壓無接觸）、任一指標超過設計上下限，或最大壓縮率超過規格書實測曲線最大上限（材料已達極限無法繼續壓縮）。

3. AI Datasheet PDF 匯入與雲端資料庫

• 開啟網頁會自動載入 Google Sheets 雲端材料庫；點擊「AI 匯入 PDF」可勾選規格書圖表頁自動擷取全系列厚度 SKU 並換算標準單位。

• 寫入或覆寫雲端前皆會自動比對重複與差異並依「品牌 → 系列 → 厚度」整齊排序。
